# AuroraWeave technical evidence pack

## Non-confidential summary

AuroraWeave is an early-stage research concept for a woven thermal-protection-system architecture. The working question is whether a continuous, Möbius-inspired weave can improve a defined interface, load-path, edge-management, or thermal-cycling problem relative to an explicit baseline material system.

This document deliberately makes no performance, temperature, cost, reuse-count, flight-readiness, or licensing claim.

## Required definition before any test

- **Architecture:** drawing showing fibre paths, repeat unit, edge/termination condition, and attachment interface.
- **Constituents:** fibre type, matrix, coating, binder, porosity target, density, thickness, and cure/firing process.
- **Target use case:** one component and one environment; for example, a moderate-flux reusable acreage panel, an insulated structural panel, or a high-heat-flux leading-edge subcomponent. Do not claim all three.
- **Comparator:** a commercially available or literature-documented material system appropriate to that use case.
- **Mechanism:** one falsifiable statement describing the predicted benefit and why it should occur.

## Initial coupon test matrix

| Test | What it establishes | Minimum record |
| --- | --- | --- |
| Visual, dimensional, mass, density | Fabrication repeatability | Batch number, dimensions, photos, scale result |
| Microscopy and chemistry | Fibre/matrix/coating structure | Instrument, settings, representative images |
| Thermal exposure | Surface and backside response | Temperature-time history, heating rate, atmosphere, thermocouple placement |
| Oxidation / mass loss | Material stability | Pre/post mass, exposure conditions, repeat samples |
| Mechanical retention | Damage after exposure | Test method, load-displacement curve, failures |
| Thermal cycling | Reuse hypothesis | Cycle definition, count, inspection after each cycle |
| Baseline comparison | Commercial relevance | Identical conditions and sample geometry |

## Decision gates

1. **Fabrication gate:** Can three nominally identical coupons be made?
2. **Mechanism gate:** Is there a measurable difference from the baseline under one defined condition?
3. **Repeatability gate:** Does the result repeat across at least three specimens?
4. **Independent-review gate:** Does a qualified materials/TPS reviewer agree that the data supports a narrow next experiment?
5. **Advanced-test gate:** Only then consider specialist high-enthalpy or arc-jet testing.

## Material for a technical reviewer

When requested, provide only:

1. This non-confidential summary.
2. One architecture sketch with sensitive details omitted until IP advice.
3. A one-page test proposal naming the baseline and success/failure criteria.
4. Raw data once tests exist.

Do not provide financial details, licence terms, a price, claims of “infinite” performance, or broad spaceflight marketing claims.
